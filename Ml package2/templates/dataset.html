Severity Mapping

Mapping of attack categories to four severity levels

The UNSW-NB15 dataset contains 10 attack categories. To predict the severity of an attack, each category is mapped to one of four understandable severity levels:

LOW {{ severity_counts.get('LOW', 0) }} records
Normal

Normal network traffic with no malicious activity.

MEDIUM {{ severity_counts.get('MEDIUM', 0) }} records
Reconnaissance, Analysis, Fuzzers

Probing, port scanning, and automated input testing.

HIGH {{ severity_counts.get('HIGH', 0) }} records
DoS, Exploits, Generic

Denial of service and known exploits targeting system availability.

CRITICAL {{ severity_counts.get('CRITICAL', 0) }} records
Backdoor, Shellcode, Worms

Arbitrary code execution, unauthorized remote access, and spreading malware.
