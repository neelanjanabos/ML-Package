Performance Analysis

Understanding why algorithm performance varies

Decision Tree & KNN

Decision Tree and KNN perform best (~85% accuracy). Network traffic data contains non-linear relationships and clear threshold boundaries (such as packet counts and durations) that tree-based partitioning and distance-based clustering capture well.

Naive Bayes & Linear Models

Naive Bayes assumes that all input features are independent. However, network traffic features (like bytes, packets, and duration) are correlated, which reduces its accuracy (~55%). Logistic Regression and Linear SVM achieve moderate performance (~73%) using linear separation boundaries.
